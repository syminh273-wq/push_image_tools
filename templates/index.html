Add account

      

        Enter a profile name (e.g. pro_01), the Gmail and its password, then press Add & sign in.
        A Chrome window opens and the tool fills Google's sign-in form for you; if Google asks for
        2-Step Verification, confirm it on your phone — or give the Authenticator key (Google Account →
        2-Step Verification → Authenticator → "Can't scan it?") and the code is entered for you. The password is kept in the macOS Keychain
        (not in this folder), so the account signs back in by itself when a scan finds it signed out.
        Leave Gmail/password empty to type them in the window yourself. Entering a password for an
        existing profile name updates it.
